# AS Roma Cards

Automated AS Roma football data dashboard and social-media card generator.

## Planned features

- AS Roma match results and upcoming fixtures.
- Serie A, Coppa Italia and UEFA competition data.
- Standings and tournament status.
- Full squad and player information.
- Match events, including goals and cards.
- English and Bulgarian card versions.
- 1080 × 1350 downloadable social-media cards.
- Roma red/gold dark visual theme.
- Oswald typography.
- Automated SportMonks data updates.
- Operator approval through GitHub pull requests.
- Netlify frontend deployment.

## Project status

Initial repository setup.

## Security

API tokens must never be committed to this repository. Use GitHub Actions Secrets for the SportMonks token.
